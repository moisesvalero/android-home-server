# Perfil de Usuario y Preferencias (Plantilla)

- **Ubicación:** Define tu ciudad, región o huso horario para adaptar las búsquedas locales.
- **Idiomas:** Español por defecto.
- **Objetivos de empleo:** Define tus puestos prioritarios y tecnologías preferidas en `.env` (variables `JOB_SEARCH_LOCATIONS` y `JOB_SEARCH_KEYWORDS`).
- **Intereses de chollos:** Define categorías o dispositivos de interés en `DEALS_KEYWORDS`.
